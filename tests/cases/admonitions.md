## GitHub 告示框

### WARNING

> [!WARNING]
> 最容易漏的是安培力
> 最容易漏的是安培力，最容易画错方向的也是安培力。切记：只要回路里有电流，杆又在磁场里，就一定有安培力；电流为零时安培力才为零。

### NOTE

> [!NOTE]
> 补充一条说明：**粗体**、$F=ma$ 与 `行内代码` 都可以放进告示框正文，连续多行会自动合并成一个段落。

### TIP 自定义标题

> [!TIP] 快速检查
> 先看回路里有没有电流，再看导体杆是否处在磁场里。

### IMPORTANT

> [!IMPORTANT]
> 优先级：电流 + 磁场 → 必有安培力；电流为零 → 安培力为零。

### CAUTION

> [!CAUTION]
> 方向容易画反，务必再用左手定则核对一遍。
