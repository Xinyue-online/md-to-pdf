%   1) 紧跟 documentclass 的那行「符号回退占位符」：两个下划线夹住

%   2) fancyhdr 页眉那行的「页眉占位符」：两个下划线夹住 PAGE 与 HEADER

%   3) 正文起点标记，也就是文件末尾那个 document 环境开头。封面配色、

%      目录 / 正文。
%
% 注意：三样东西都不要在本注释里写出完整字面量。转换做的是全文文本替换，
% 注释里写全了会被一起替换掉、导言区错位。load_template 用「必须恰好出现
% 一次」的校验把这种情况拦成报错。
%

% ===========================================================================

%----- 交给 CJK 字体的码位（xeCJK 字符类）-----
% 中文字体（SimSun / FangSong）自带的符号比西文主字体（Latin Modern）多，
% 落在西文字体上的符号，LM 没有字形就是一片空白（Ⅰ Ⅱ Ⅲ、■ □、─ │、′ ″）。
% 下面这些码位声明成 CJK 字符类，改由中文字体排版。
% 表是量出来的（measure_coverage.py 会重算）：只收 SimSun 与 FangSong 都有
% 字形、而 Latin Modern 没有的码位。每段必须是连续区间——段里夹进西文字体本来
% 就能显示的字符，声明过去反倒把它弄坏。改完跑 test_symbol_fallback.py。
\xeCJKDeclareCharClass{CJK}{
  "0370 -> "03FF,                          % 希腊字母（3σ、均值 μ）
  "2015, "2032 -> "2033, "2035,            % ― 角分秒 ′ ″ ‵
  "2070 -> "209F,                          % 上下标 ⁰¹² ₀₁₂（中文字体有字形的部分）
  "2105, "2109, "2121,                     % ℅ ℉ ℡
  "2160 -> "216B, "2170 -> "2179,          % 罗马数字 Ⅰ-Ⅻ 与 ⅰ-ⅹ
  "2190 -> "21FF,                          % 箭头 → ← ↑ ↓ ↖↗↘↙
  "2200 -> "22FF,                          % 数学运算符 ∈ ∑ ∏ √ ≤ ≥ ∴ ∵ 等
  "2312,                                   % ⌒
  "2460 -> "24FF,                          % 带圈数字 ①②③ ⑴⒈
  "2500 -> "254B, "2550 -> "2573,          % 制表符 ─ │ ┌ ┐ └ ┘ ├ ┤
  "2581 -> "258F, "2593 -> "2595,          % 方块元素 ▁▂▃█▌▐
  "25A0 -> "25A1, "25B2 -> "25B3, "25BC -> "25BD, "25C6 -> "25C7,
  "25CB, "25CE -> "25CF, "25E2 -> "25E5,   % ■□▲△▼▽◆◇○◎●◢◣◤◥
  "2605 -> "2606, "2609, "2640, "2642     % ★☆☉♀♂
}
