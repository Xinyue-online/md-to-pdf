import pandas as pd

df = pd.read_csv("sales.csv", encoding="utf-8-sig")
df = df.dropna(subset=["amount"])
df["date"] = pd.to_datetime(df["date"])
print(df.head())
\end{lstlisting}

\subsection{数据清洗要点}

\begin{itemize}
\item 缺失值：\texttt{dropna} / \texttt{fillna} 二选一
\begin{itemize}
\item 直接删除行 → 样本量损失
\item 均值/中位数填充 → 引入偏差
\end{itemize}
\item 重复值：\texttt{drop\_duplicates} 按关键列去重
\item 异常值：3σ 原则或 IQR 方法剔除
\end{itemize}

按步骤执行：

\begin{enumerate}
\item 先探查 \texttt{df.info()} 与 \texttt{df.describe()}
\item 再处理缺失与重复
\item 最后统一数据类型
\item 校验结果写入新文件
\end{enumerate}

\subsection{引用与脚注}

\begin{mdpdfquote}
数据清洗是整个分析流程中最耗时的一步，通常占全部工作量的 60\% 以上。
\end{mdpdfquote}

有人建议把清洗规则写成配置项\footnote{配置化清洗规则便于团队协作与规则复用。}，以便复现与审计。公式示例：质能方程 $E = mc^2$，以及更复杂的 $f(x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$。
